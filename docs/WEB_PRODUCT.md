# Campus: краткое руководство

## Вход и учётная запись

Откройте HTTPS-адрес Campus, который предоставил администратор. Если используется
локальный центр сертификации, получите его публичный сертификат у администратора
и настройте доверие на своём устройстве.

Зарегистрируйтесь с именем, email и паролем, затем входите по email и паролю.
Регистрация создаёт обычного участника. Права администратора выдаются отдельно;
совпадение email с адресом владельца их не предоставляет. Существующий владелец
может войти по приватному одноразовому приглашению и настроить пароль аккаунта.
Не передавайте пароль или приглашение другим людям.

## Подключение компьютера

На странице устройств выполните три шага:

1. Скачайте небольшой файл запуска **Connect** для своей ОС.
2. Откройте файл на компьютере, который будет участвовать в вычислениях.
   На Windows и macOS заранее установите и запустите **Docker Desktop вручную**.
   На Linux нужен работающий Docker Engine.
3. Создайте на странице отдельное приватное приглашение для своего компьютера,
   скопируйте его и вставьте в открытый клиент. Приглашение одноразовое и действует
   30 минут. Сам файл Connect не заменяет приглашение.

Если macOS не открывает скачанный файл, в «Терминале» выполните
`sh ~/Downloads/Connect.command`, как подсказывает страница. Следуйте локальным
подсказкам клиента и оставьте его окно открытым на время участия. Браузер не может
сам установить Docker или запустить клиент на другом компьютере.

GPU разрешается отдельно, непосредственно в клиенте. Для CUDA нужен совместимый
NVIDIA GPU и рабочая поддержка GPU в Docker. На macOS используйте CPU: Metal и
CUDA через этот клиент не предоставляются. Работа от батареи также требует
локального разрешения. Переключение режима нагрузки не выдаёт эти разрешения.

## Нагрузка и остановка

В карточке своего устройства выберите режим:

| Режим | Доля доступных CPU и памяти | Когда использовать |
| --- | --- | --- |
| Лёгкий (`low`) | 10% | Вы продолжаете работать за компьютером |
| Средний (`medium`) | 50% | Нужен баланс нагрузки и скорости |
| Максимальный (`max`) | 90% | Компьютер свободен и подключён к питанию |

Проценты относятся к **локально доступным** CPU и памяти. Доступная ёмкость Docker,
настройки владельца и локальное согласие могут дополнительно ограничить бюджет.
Фактически выделенные ресурсы показаны в карточке.

**Пауза** приостанавливает участие. **Подключить / продолжить** возобновляет его,
если клиент запущен. **Завершить текущую работу** позволяет закончить текущую
работу без получения новой. После команды дождитесь сообщения о применении:
состояние «Ожидает применения» означает, что клиент ещё не подтвердил изменение.
Если компьютер не в сети, откройте клиент на нём. Для старого клиента может
потребоваться обновление.

Чтобы полностью прекратить участие локально, завершите клиент, например через
Ctrl+C. Команда из браузера не запустит закрытый клиент; для нового подключения
его нужно открыть на самом компьютере.

## Своя задача и помощь ИИ

На странице новой задачи можно начать с примера на CPU или NVIDIA GPU либо
подготовить собственную работу:

1. Опишите результат, который нужен, и добавьте входные файлы. Для собственного
   кода выберите ZIP проекта или папку. Удалите из проекта пароли, ключи и другие
   секреты до загрузки.
2. Просмотрите показанные текстовые файлы проекта и **явно отметьте** только те,
   чей текст разрешаете передать ИИ. По умолчанию они не выбраны. Просмотр ZIP
   показывает ограниченное число небольших текстовых файлов, а не весь архив.
3. Отдельно подтвердите отправку описания и выбранного текста в DeepSeek и
   нажмите **Подготовить план**. ИИ получает описание, сведения о входных файлах
   и выбранные фрагменты; код и данные для выполнения загружаются в пул.
4. Ответьте на уточняющие вопросы, если они появились. Проверьте предложенный
   план, совместимость устройств, ресурсы и ограничения. При недоступном ИИ
   прочитайте ошибку; ожидание ответа не означает запуск вычислений.
5. Запустите работу только после проверки плана. На странице задачи следите за
   состоянием, прогрессом и журналом. Готовые опубликованные файлы скачивайте
   из результатов; при необходимости отмените работу.

Выполнение требует совместимого профиля и доступного устройства. Произвольный
ZIP не гарантирует совместимость с пулом. Наличие выходного файла само по себе
не подтверждает качество модели; ориентируйтесь на статус проверки результата.

## Статистика и администрирование

На главной странице отображаются ваши устройства, задачи и измеренный вклад.
Пустая история означает отсутствие записанной активности. Участник видит свои
данные; владелец или администратор может открыть `/admin/` на том же HTTPS-сервере
для обзора пула и управления устройствами и задачами в пределах своих прав.

Развёртывание, сохранение данных, приватная конфигурация и обновление описаны
в [руководстве оператора](WEB_OPERATIONS.md).
